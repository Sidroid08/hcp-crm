# Architecture

## System Shape

This project is a full-stack CRM workflow module optimized for HCP interaction logging.

- React/Vite frontend for dashboard, logging, and interaction history workflows.
- FastAPI backend for CRUD, AI workflow endpoints, and operational health checks.
- SQLAlchemy data layer with SQLite for local development and PostgreSQL-compatible configuration.
- LangGraph CRM agent backed by Groq or local Ollama/Llama 3.2.
- Alembic migration scaffold for controlled schema changes.

## AI Workflow

The conversational logger accepts natural-language interaction notes and returns two outputs:

- A representative-facing reply generated by the configured LLM.
- A structured draft enriched by deterministic CRM tools for reliability.

This split keeps demos responsive and predictable while still using an LLM for the conversational experience.

## Reliability Posture

- API tests isolate database state with in-memory SQLite.
- Frontend API errors preserve backend validation details.
- `/health` exposes environment, database dialect, and LLM provider metadata.
- Docker Compose provides a reproducible local runtime.
- GitHub Actions runs backend tests and frontend builds on pull requests and pushes.

## Recruiter Demo Path

1. Start Ollama with `llama3.2`.
2. Run backend and frontend locally, or use `docker compose up --build`.
3. Open the dashboard.
4. Use an AI prompt starter in Log Interaction.
5. Save the generated draft.
6. Show History search, edit, delete confirmation, and API docs.
